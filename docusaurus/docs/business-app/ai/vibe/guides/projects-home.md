# Projects Home & Templates

## What is the Projects Home?

The Vibe home is where every build begins. It opens with a "What should we build today?" composer — a single prompt box with build-mode selection and voice input — and two tabs beneath it: **Templates** and **My Projects**.

Instead of starting from an empty field, you arrive at working examples. Browse the template gallery for something close to what you have in mind, or describe your idea in the composer and build from scratch.

## Why is the Projects Home important?

- **Start from a working example**: Templates give you a functioning starting point, so you refine something real rather than describing everything from zero.
- **Know before you commit**: Each template's detail view shows exactly what it does and what it requires, so you can choose with confidence.
- **Your project is yours**: Creating a project from a template gives you an independent copy — changes you make don't affect the template.
- **Stay organized as you grow**: Project tags and search on the My Projects tab keep your builds easy to find.

## What's included with the Projects Home?

- **Composer**: One prompt box at the top of the home — "What should we build today?" — with build-mode selection and voice input.
- **Templates tab**: A searchable template gallery. Each card shows cover imagery and a plain-language description of what the template does, with search and a browse-all view.
- **Template detail view**: An image carousel, a description, the publish date, and the connectors the template requires — so you know what you're getting before you commit.
- **My Projects tab**: Your projects, with project tags and search to organize and find them. Each project card shows a live preview thumbnail.

## How to use the Projects Home

### Browse and search templates

1. Open Vibe. The home appears with the composer at the top.
2. Select the **Templates** tab.
3. Browse the gallery cards, or use search to find a template. Each card shows cover imagery and a plain-language description of what the template does.
4. Use browse-all to see the full gallery.

### Review a template before you commit

1. In the **Templates** tab, select a template.
2. The detail view opens with an image carousel, a description, the publish date, and the connectors the template requires.
3. Review what the template does and what it needs before creating a project from it.

### Create a project from a template

1. Open a template's detail view.
2. Use the create action to make a working project from the template.
3. Vibe creates an independent project that's yours to change — edits to your project don't affect the template.

### Start from a prompt instead

1. From the home, type what you want to build in the "What should we build today?" composer — or use voice input to describe it.
2. Choose the build mode for your prompt.
3. Send it to start building.

### Organize and find your projects

1. Select the **My Projects** tab to see your projects. Each project card shows a live preview thumbnail.
2. Use project tags to organize your projects.
3. Use search to find a specific project.

## Frequently Asked Questions

<details>
<summary>Do I have to start from a template?</summary>

No. Templates are one starting point. You can also describe what you want in the composer — by typing or with voice input — and build from scratch.
</details>

<details>
<summary>If I change my project, does the template change too?</summary>

No. Creating a project from a template gives you an independent working project. Your changes stay in your project and don't affect the template.
</details>

<details>
<summary>How do I know what a template requires before I use it?</summary>

Open the template's detail view. It shows an image carousel, a description, the publish date, and the connectors the template requires, so you know what you're getting before you commit.
</details>

<details>
<summary>How do I find a project I built earlier?</summary>

Open the **My Projects** tab. Use search to find a project by name, or use project tags to organize and filter your builds. Each card shows a live preview thumbnail so you can spot the right project at a glance.
</details>
