File Management gives multi-location accounts a shared place to upload, organize, and find files and folders. Assets you upload here are available for reuse in the Social Marketing Composer at both the single-location and multi-location level.

File Management is available for multi-location accounts on web and mobile.

## Why use File Management?

- **Reuse assets everywhere**: Upload a file once and use it across your locations instead of re-uploading the same asset repeatedly
- **Keep brand assets consistent**: Store approved logos, images, and videos in a shared folder that every location can pull from
- **Find files faster**: Search and filter files by name and description instead of scrolling through folders

## What's included with File Management?

- **Brand Assets folder**: A default folder for storing approved brand assets. It can't be deleted, and you can't create another folder with the same name.
- **Upload**: Upload individual files or entire folders.
- **New Folder**: Create folders to organize your files.
- **Search**: Search files by filename and description.
- **Column filters**: Filter the file and folder list by column.
- **List and Thumbnail views**: Switch between a detailed list view and a visual thumbnail view.
- **Pagination**: Browse large file and folder lists a page at a time.

## How to use File Management

### Go to File Management

1. From your Multi-Location Business App, go to `CRM`.
2. Select `File Management`.

You always start inside a folder. The Brand Assets folder is available by default and can't be removed.

### Upload files or folders

1. Go to `CRM` → `File Management`.
2. Click `Upload`.
3. Choose the files or folders you want to upload.

Upload limits:

- **Images**: Up to 10 image files per upload, each up to 10 MB.
- **Videos**: Up to 5 video files per upload, each up to 1 GB.

### Create a folder

1. Go to `CRM` → `File Management`.
2. Click `New Folder`.
3. Enter a name and confirm.

:::note
You can't name a folder "Brand Assets". That name is reserved for the default folder.
:::

### Upload to the Brand Assets folder

1. Go to `CRM` → `File Management` and open the `Brand Assets` folder.
2. Click `Upload` and choose your files.

Assets in the Brand Assets folder are available in the Social Marketing Composer for both single-location and multi-location accounts.

### Search, filter, and sort files

1. Go to `CRM` → `File Management`.
2. Use the search box to find a file by filename or description.
3. Use column filters and sort options to narrow the list further.
4. Switch between `List` and `Thumbnail` view depending on how you want to browse.

### Delete a file

1. Go to `CRM` → `File Management`.
2. Select the file you want to remove.
3. Choose `Delete` and confirm.

:::info
You can delete individual files. Deleting a folder isn't supported.
:::

## Frequently asked questions

<details>
<summary>Who can use File Management?</summary>

File Management is available to multi-location accounts.
</details>

<details>
<summary>Can I preview a file before downloading it?</summary>

No. Download a file to view its contents.
</details>

<details>
<summary>Can I delete a folder?</summary>

No. You can delete individual files, but folder deletion isn't supported.
</details>

<details>
<summary>Can I rename the Brand Assets folder or create a duplicate?</summary>

No. Brand Assets is a default folder and can't be deleted. You also can't create a new folder named "Brand Assets" since that name already exists.
</details>

<details>
<summary>How many files can I upload at once?</summary>

Up to 10 images (10 MB each) or up to 5 videos (1 GB each) per upload action.
</details>

<details>
<summary>Where can assets from the Brand Assets folder be used?</summary>

They're available in the Social Marketing Composer for both single-location and multi-location accounts.
</details>

<details>
<summary>Is File Management available on mobile?</summary>

Yes. File Management is supported on both web and mobile.
</details>

<details>
<summary>Can I search for a file by its description instead of its name?</summary>

Yes. The search box matches both filename and description.
</details>
