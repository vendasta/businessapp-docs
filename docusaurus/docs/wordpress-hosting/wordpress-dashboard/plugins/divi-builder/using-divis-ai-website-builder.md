## Boost your web design workflow with Divi's built-in AI

Divi's built-in AI helps you build websites by simplifying design and content creation. With tools embedded directly into the Divi interface, you can generate custom layouts, write text, create visuals, and produce code without leaving the design environment.

Divi AI uses your website's existing content and style to help write brand-consistent copy, such as product descriptions, headlines, and blog content. Everything is available in the builder.

## How Divi AI enhances your site

Divi AI uses your site's look, feel, and messaging as context. You can use it to generate new page layouts, create images from prompts, or write text.
